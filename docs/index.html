数据、实现与使用边界

观看 35 秒实际页面操作演示（静音）

网页在本地比较六份历史核价餐单，不连接你的麦当劳账号，不收集 Token。三个角色是可检查的规则审阅器，不冒充三个独立大模型。配套 Skill 可由支持子任务的 AI 客户端组织角色审阅。

营养数值来自官方标准份量单品表的加总，实际制作可能不同；辣味标签由模板明确指定，不代表过敏原判断。比较范围仅为这六份餐单，不保证全菜单最低价。网页没有下单、支付或领券功能，也没有分析追踪器。

历史快照不可作为当前报价。使用本机 Python 的 --live 模式可以重新核价；查询失败会停止，不会偷偷换成示例数据。
