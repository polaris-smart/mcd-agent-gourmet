数据、实现与使用边界
观看旧版 35 秒页面操作演示（静音，界面以当前页面为准）
网页在本地比较已收录的历史核价餐单，不连接你的麦当劳账号，不收集 Token。程序按价格、已知钠含量和口味匹配进行确定性比较，没有三个独立模型讨论。同一餐单可能符合多个标准。配套 Skill 帮助 AI 客户端理解需求、查询并解释结果。
营养数值来自官方标准份量单品表的加总，实际制作可能不同；辣味标签由模板明确指定，不代表过敏原判断。比较范围仅为所选样例中的候选餐单，不保证全菜单最低价。网页没有下单、支付或领券功能，也没有分析追踪器。
历史快照不可作为当前报价。使用本机 Python 的 --live 模式可以重新核价；查询失败会停止，不会偷偷换成示例数据。
